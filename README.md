# Injetech Soluções Automotivas - site institucional

Site one-page da **Injetech Soluções Automotivas**, oficina mecânica em Goiânia - GO.

## Estrutura

```
index.html   # página única (hero, sobre, serviços, depoimentos, mapa, FAQ)
styles.css   # estilos (neutros + vermelho da marca, tema claro/escuro automático)
script.js    # menu mobile, header ao rolar, animações de entrada, carrossel, FAQ
assets/      # logo, favicon e fotos
```

Sem build: HTML, CSS e JS puros. Publique a pasta em GitHub Pages, Netlify, Vercel ou hospedagem comum.

- **Horário**: o perfil mostra 08:00 - 18:00. Confirme os dias (o site diz segunda a sexta) e se abre aos sábados.
